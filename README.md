# Dharsan Sangeesh — Portfolio

This is a minimal personal portfolio site scaffold with sample projects and contact info.

Open `index.html` in a browser to view.

To customize:
- Update contact info and projects in `index.html`.
- Replace the sample GitHub link with your profile URL.
- Edit `styles.css` to change colors and spacing.

Sample projects in the site link to example.com placeholders. Replace them with your live demos or repository URLs.
